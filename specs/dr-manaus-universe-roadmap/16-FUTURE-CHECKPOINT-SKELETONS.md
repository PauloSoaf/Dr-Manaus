## C1 — TARGET-LOCK

### First actions

- confirm branch and HEAD
- inspect current implementations touched by this checkpoint
- inspect changes since this package HEAD
- write a failing regression that proves the missing capability

- preserve one scheduler
- keep collision/detection separate from rendering
- report automatic versus manual verification separately

- finish only C1
- update authoritative docs with measured results
- commit meaningful code/tests/docs
